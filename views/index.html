Writing one

A plugin adds a view here, commands after ws, and a guide that tells agents they're there. This starts one that works as it's written:

ws plugin-dev new notes
cd plugin-notes
ws plugin-dev watch

watch builds it and runs it in this workspace, and again on every save. Its page reloads itself, and how each build went shows here.
